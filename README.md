# Arduino LCD Button Project

My first Arduino project, simulated using Wokwi.

## About

This project uses an Arduino Uno, a push button, an LED, and a 16x2 LCD.

When the button is pressed, the LED state changes and the current LED state is displayed on the LCD.

## Components

- Arduino Uno
- 16x2 I2C LCD
- Push Button
- LED

## Tools Used

- Arduino
- Wokwi
- C/C++

## What I Learned

- Arduino digital input and output
- Push-button interfacing
- LCD interfacing
- Basic embedded C programming
- Circuit simulation using Wokwi
